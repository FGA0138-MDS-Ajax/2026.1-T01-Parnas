# Presenças (gov.br)

Esta seção reúne as **listas de presença** das reuniões obrigatórias do Grupo
Parnas, **assinadas digitalmente** pelos integrantes por meio da plataforma
[**gov.br**](https://www.gov.br/governodigital/pt-br/assinatura-eletronica),
garantindo autenticidade e validade jurídica dos registros.

---
## Como funciona

1. Ao final de cada reunião, gera-se o **documento de presença** (PDF).
2. Cada integrante presente **assina digitalmente** o documento via gov.br
   (assinatura eletrônica avançada/qualificada).
3. O PDF assinado é arquivado e indexado nesta página.
