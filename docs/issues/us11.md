## História de usuário
Como Gestor de uma Micro-Empresa, quero cadastrar despesas e receitas futuras com data de vencimento, para acompanhar meus compromissos financeiros e não perder prazos.

## Rastreabilidade

- **Cenário:** CEN-01 — Registro de dados financeiros
- **Sprint:** 7
- **Prioridade:** Should
- **Funcionalidade do produto:** J — Cadastro de Contas

## Critérios de aceitação
- [x] Gestor consegue cadastrar conta com descrição, valor, tipo, vencimento e categoria
- [x] Contas são listadas separadas por pendentes e quitadas
- [x] Gestor consegue quitar uma conta pendente com confirmação
