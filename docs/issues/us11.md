## História de usuário
Como Gestor de uma Micro-Empresa, quero cadastrar despesas e receitas futuras com data de vencimento, para acompanhar meus compromissos financeiros e não perder prazos.

## Rastreabilidade
- **Requisito(s):** R15
- **Cenário:** CEN-01 — Registro de dados financeiros
- **Sprint:** 7
- **Prioridade:** Should
- **Funcionalidade do produto:** J — Cadastro de Contas

## Critérios de aceitação
- [ ] Gestor consegue cadastrar conta com descrição, valor, tipo, vencimento e categoria
- [ ] Contas são listadas separadas por pendentes e quitadas
- [ ] Gestor consegue quitar uma conta pendente com confirmação
- [ ] Ao quitar uma conta, é gerada automaticamente a transação correspondente
- [ ] Contas quitadas não podem ser editadas nem excluídas
- [ ] Gestor consegue editar e excluir contas pendentes
