## História de usuário
Como usuário cadastrado em mais de uma empresa, quero escolher qual empresa está ativa na minha sessão, para que todos os dados exibidos e cadastrados sejam referentes a ela.

## Rastreabilidade
- **Requisito(s):** R04
- **Cenário:** CEN-00 — Plataforma e autenticação
- **Sprint:** 7
- **Prioridade:** Should
- **Funcionalidade do produto:** A — Cadastro e Autenticação de Usuário/Empresa

## Critérios de aceitação
- [ ] Após login, se o usuário pertence a mais de uma empresa, o sistema exibe uma tela de seleção de empresa
- [ ] Se o usuário pertence a apenas uma empresa, ela é selecionada automaticamente
- [ ] Usuário consegue trocar a empresa ativa sem precisar fazer logout
- [ ] Todas as requisições subsequentes usam o id_empresa da empresa ativa
- [ ] Empresa ativa fica disponível no EmpresaContext do frontend
- [ ] Ao trocar de empresa, os dados de todas as telas são recarregados para refletir a nova empresa

## Tarefas Banco de Dados
