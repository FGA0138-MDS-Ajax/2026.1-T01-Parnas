## História de usuário
Como Gestor de uma Micro-Empresa, quero simular operações de crédito informando valor, prazo, modalidade e taxa de juros, para entender o impacto no fluxo de caixa antes de decidir captar recursos.

> **US irmã (backend):** esta issue concentra a camada de **backend** da Simulação de
> Crédito. O **frontend** > correspondente é a US irmã US10 — Simulação de Crédito (Frontend). As duas
> compõem a mesma funcionalidade **H — Simulação de Crédito**, separadas por camada. Branch: `feature/13-simulacao-creditos`.

## Rastreabilidade
- **Requisito(s):** R12

- **Sprint:** 9

## Critérios de aceitação

### Cálculo (Price / SAC)
- [x] **CA-01** Price gera parcelas de valor igual e, ao fim do prazo, o saldo devedor zera (± R$ 0,01)
- [x] **CA-02** Com taxa de juros 0, a parcela = valor ÷ prazo e o total de juros é 0
- [x] **CA-03** SAC tem amortização constante, parcelas decrescentes e total de juros menor que o Price para os mesmos parâmetros
- [x] **CA-04** O endpoint `POST /simulacoes/calcular` retorna o detalhamento (parcela, total, juros, cronograma) **sem gravar** nada no banco
- [x] **CA-05** Informando a empresa, o cálculo anexa a projeção de impacto no fluxo de caixa; sem histórico de transações, retorna status "Indisponível"

### Persistência e listagem
- [x] **CA-06** `POST /simulacoes` salva a simulação e retorna o `id_simulacao`; os valores (parcela, total, juros) são calculados no backend, não vêm do front
- [x] **CA-07** `GET /simulacoes` lista apenas as simulações da empresa informada, com data e parâmetros
- [x] **CA-08** `DELETE /simulacoes/<id>` remove a simulação da empresa (some da listagem); id inexistente retorna 404
- [x] **CA-09** Ao excluir a empresa, suas simulações são removidas em cascata (FK `ON DELETE CASCADE`)

### Validações e segurança
- [x] **CA-10** Entradas inválidas retornam 400: modalidade fora de PRICE/SAC, valor ≤ 0, prazo ≤ 0
- [x] **CA-11** Taxa de juros 0 é aceita (juros zero)
- [x] **CA-16** Todos os endpoints exigem autenticação (401 sem token)

> Os critérios de **frontend** (CA-12…CA-15) pertencem à US irmã.
