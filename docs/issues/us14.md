## História de usuário
Como Gestor de uma Micro-Empresa, quero comparar diferentes modalidades de crédito lado a lado, para escolher a linha mais adequada ao meu negócio e evitar o uso de crédito de pessoa física.

## Rastreabilidade
- **Requisito(s):** R13
- **Cenário:** CEN-04 — Diagnóstico e simulação de crédito
- **Sprint:** 9
- **Prioridade:** Should
- **Funcionalidade do produto:** I — Comparação de Modalidades de Crédito

## Critérios de aceitação
- [x] Gestor consegue adicionar até 4 modalidades para comparar
- [x] Cada modalidade tem nome, taxa de juros, prazo e tipo (PF/PJ)
- [x] Sistema calcula e exibe parcela, total pago e total de juros para cada
- [x] Sistema destaca visualmente a modalidade mais vantajosa

- [x] Gestor consegue exportar a comparação como PDF
