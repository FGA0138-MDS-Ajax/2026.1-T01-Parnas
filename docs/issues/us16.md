## História de usuário
Como Gestor de uma Micro-Empresa, quero um dashboard financeiro consolidado, para visualizar dados reais e centralizados da minha empresa ativa assim que acessar o sistema, eliminando a necessidade de consultar múltiplos relatórios separados.

## Rastreabilidade
- **Requisito(s):** R09
- **Cenário:** CEN-01 — Registro de dados financeiros
- **Sprint:** 7
- **Prioridade:** Must
- **Funcionalidade do produto:** E — Dashboard Financeiro
