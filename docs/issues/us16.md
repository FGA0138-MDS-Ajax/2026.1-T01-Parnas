## História de usuário
Como Gestor de uma Micro-Empresa, quero um dashboard financeiro consolidado, para visualizar dados reais e centralizados da minha empresa ativa assim que acessar o sistema, eliminando a necessidade de consultar múltiplos relatórios separados.

## Rastreabilidade
- **Requisito(s):** R09
- **Cenário:** CEN-01 — Registro de dados financeiros
- **Sprint:** 7
- **Prioridade:** Must
- **Funcionalidade do produto:** E — Dashboard Financeiro

## Critérios de aceitação
- [ ] A página do Dashboard é criada na interface
- [ ] Exibe o **saldo atual** consolidado (calculado a partir de todas as transações reais)
- [ ] Exibe os totais de **receitas e despesas** referentes apenas ao **mês atual**
- [ ] Exibe um **gráfico de distribuição por categoria** baseado nos gastos reais do mês atual
- [ ] Exibe uma listagem de **contas pendentes próximas do vencimento**
- [ ] Dados estáticos/mockados são 100% removidos da tela após o carregamento
- [ ] O Dashboard reage e atualiza os dados quando a empresa ativa é alterada (integração com us15)

## Tarefas Banco de Dados
- [ ] Criar query de agregação específica para "próximos vencimentos" (contas PENDENTES, ordenadas por data_vencimento mais próxima, limitadas a X registros)
- [ ] Garantir que as consultas do Dashboard usem índices de data e id_empresa para evitar gargalos na tela inicial

## Tarefas Backend
- [ ] Criar DashboardService para centralizar as regras e buscas da tela inicial
- [ ] Reutilizar os métodos de agregação de período e categoria do ReportService (evitando duplicação de lógica)
- [ ] Criar o endpoint GET /api/dashboard retornando saldo, totais mensais, dados do gráfico e contas próximas do vencimento em uma única resposta JSON, filtrando pela empresa ativa do token/sessão
