# Documentação de Testes por Tarefa Técnica

Além das features, a dupla de Qualidade avalia as **tarefas técnicas de integração
e refatoração**. Por consolidarem várias frentes, essas tarefas são avaliadas com
**rigor**: ou estão íntegras (**Aprovada**), ou são **Reprovadas** com os defeitos
apontados - não há "aprovada com pendências".

## Status possíveis

| Status            | Significado                                                        |
|-------------------|-------------------------------------------------------------------|
| **Aprovada**    | Integração íntegra; pode ser mesclada                             |
| **Reprovada**   | Há defeito bloqueante; volta para desenvolvimento com os apontamentos |
