# Consolidados por Sprint

A cada Sprint a dupla de Qualidade produz dois artefatos agregados:

- **Consolidado de Testes** — features testadas, casos agregados, defeitos,
  números gerais e cobertura (M3), com o parecer da dupla.
- **Análise GQM** — métricas M1–M4 preenchidas, consolidado e parecer.

Ambos ficam reunidos na página de cada Sprint abaixo.
