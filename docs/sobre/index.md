# O Grupo Parnas

O Grupo Parnas é a equipe responsável pelo desenvolvimento do **CrediFab**
na disciplina de Métodos de Desenvolvimento de Software (MDS), turma T01 do
semestre 2026.1, sob orientação do professor Ricardo Ajax Dias Kosloski.

O nome é uma homenagem a **David Parnas**, um dos pioneiros da Engenharia de
Software, conhecido por trabalhos fundamentais sobre modularização,
ocultação de informação (information hiding) e especificação de
software — princípios que o grupo busca refletir na organização do código e
da documentação do projeto.

## Metodologia de Trabalho

- Metodologia *ágil* inspirada em Scrum e XP, com Sprints semanais.
- **Git Flow** como fluxo de versionamento (`main`, `develop`, `feature/*`,
  `test/*`, `fix/*`, `docs`).
- Pull Requests revisados como única forma de integrar código.
- Documentação versionada: os artefatos formais vivem no Overleaf e a
  documentação navegável (este site) é gerada com **MkDocs Material** a partir
  da branch `docs`.
