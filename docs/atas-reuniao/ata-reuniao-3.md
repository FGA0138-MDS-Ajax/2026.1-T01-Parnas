## Discussões e Decisões
 
**Stack:** Novamente, a equipe discutiu acerca das tecnologias a serem utilizadas, com a essência do conflito sendo a escolha de Java ou Python como linguagem principal.
 
**Reuniões:** O grupo confirmou a ideia de pequenos relatórios diários padronizados em um canal de comunicação específico. As reuniões principais serão apenas as de quarta-feira, enquanto as de sábado serão breves, uma extensão pessoal dos relatórios diários.
 
**Rotação:** A equipe decidiu abolir as decisões prévias sobre o funcionamento das duplas. Os pares terão papel fixo, mas para mantermos os fundamentos da Metodologia Ágil, iremos focar no compartilhamento dos trabalhos de cada dupla com o resto do time durante as reuniões.
